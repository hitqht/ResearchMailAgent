# M0 工程预览使用说明

本版本供开发验收，尚无普通用户安装包。按 README 的 uv 命令启动。

1. 首次打开会检查本地数据库，随后显示三步引导，可选择稍后设置。
2. 左侧导航进入今日、邮件、审稿与投稿、待办、草稿、设置。
3. 设置页可查看数据目录与迁移状态，点击“创建本地数据库备份”完成一致性备份。
4. 引导仅保存本机完成标记；无需账号或授权码，暂不连接邮箱。
5. 遇到数据异常时原文件会保留。先退出并保留原文件，不要直接删除数据库。

备份包含数据库内容，未加密，不应上传公共仓库或分享。当前日志只包含固定状态事件。
M0 不支持导入真实邮件、账户配置、模型调用或发送。相关功能将按里程碑增量交付。
