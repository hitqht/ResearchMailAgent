# M3 草稿审批开发版使用说明

本版本有本机开发 DMG。打开镜像，将应用拖至 Applications 后启动，无需开发环境。
它未经 Developer ID 签名或 Apple 公证；正式分发验收尚未完成。

1. 首次打开会检查本地数据库，随后显示三步引导，可选择稍后设置。
2. 左侧导航进入今日、邮件、审稿与投稿、待办、草稿、设置。
3. 设置页可查看数据目录与迁移状态，点击“创建本地数据库备份”完成一致性备份。
4. 在设置中添加邮箱，默认 IMAP SSL 为 imap.163.com:993。填客户端授权码后保存。
5. 如系统要求访问钥匙串，在本机界面确认；应用不使用其他程序的登录令牌。
6. 测试连接读取目录后，在邮件页选目录并点击只读同步。不会改变已读状态。
7. 默认手动同步；可设置5–1440分钟，自动同步当前目录。每批100封，有剩余可继续。
8. 搜索只查当前目录缓存的主题和发件人。正文显示为纯文本，附件仅显示元数据。
9. 遇到数据异常时原文件会保留。先退出并保留原文件，不要直接删除数据库。

备份包含数据库内容，未加密，不应上传公共仓库或分享。当前日志只包含固定状态事件。
超过20 MiB的邮件不下载正文；格式异常邮件会标注状态。已缓存账户暂不支持更换邮箱/收件服务器。
M3 支持模型分析与人工审批后发送。邮箱凭据在本机 Keychain 管理。


10. 设置页向下滚动到“模型与认证”，保存模型配置，然后从下拉列表选中并测试。
    Ollama 填实际已安装模型名与本机 IP 地址；云端填 HTTPS OpenAI 兼容 Base URL。
    API Key 用于所选认证方式，只保存于独立的模型 Keychain 服务。
11. 保存默认模型与本地优先策略。模型未配置不会妨碍只读邮箱功能。
12. 在“审稿与投稿”选择缓存邮件，点击分析。云端请求会先显示目标与完整发送内容，
    取消即不发送；授权只对本封邮件、所选模型和一次请求有效，五分钟后失效。
13. 核对摘要、引用与分类。到“待办”确认任务，手工改正或补充日期；不确定日期可留空。
14. “今日”显示已确认任务日报；可在设置开启应用内提醒并选择提前天数。
    关闭应用后不会提醒。摘要与分类是建议，系统引用检查不代表语义判断完全正确。
15. 本地模型不可用时检查 Ollama 服务和模型安装状态；不会自动把内容交给云端。
    返回 JSON、日期或证据不合法时，本次分析不保存，已有分析和任务保留。


16. 设置中选中已保存账户，可点击“测试已保存账户的 SMTP 认证（不发送）”；只检查SSL登录。
17. 到“草稿”新建空白草稿，或从当前目录缓存邮件选择来源，填写回复意图后创建回复。
    本地模型按钮仅使用已安装Ollama模型，不会使用云端默认模型，也不会自动发信。
18. 检查发件账户，逐一核对收件邮箱，编辑主题与正文。多个裸邮箱以逗号分隔；不支持抄送或附件。
19. 保存当前草稿，再依次点击“核对并标记审核”“批准当前版本”；弹窗默认取消，确认后保存状态。
20. 点击“发送已批准版本”，最后核对完整预览并明确点击“立即发送这封邮件”。SMTP成功仅表示服务器接受。
21. 内容或发件设置有改动后须重新审核。未保存修改可以保存或撤销；有修改时窗口关闭会保留当前编辑。
22. FAILED状态可重新开始审核；UNCERTAIN/结果待核实不能编辑或重发，请向服务商或收件人核查。
    不要因网页“已发送”为空便断言未提交：本应用不自动保存IMAP已发送副本。
23. 重启遇到上次发送中断时会保守转为待核实。应用不自动重发、不保证最终送达。
