# M0 界面参考与决策

## M1 沿用与验证

沿用 M0 的原生 macOS/Qt 参考锁定，不引入新的视觉系统。
用户要求的邮箱管理映射为设置表单与邮件主从视图；输入标签、可见连接反馈和异步进度遵循
内置 craft-details 规范。设置表单显式扩展输入宽度，长内容滚动；正文使用纯文本控件。
同步仅手动发起或按用户选择的周期运行，停止按钮在请求间响应。分页和本地主题/发件人搜索
避免把整个缓存一次性装入界面。M1 浅色/深色与打包后截图均在隔离合成数据下复核。

下文为保留的 M0 设计依据。

对象：macOS 科研邮件工作区。主要目标：清楚看到当前开发范围、本地隐私边界和可恢复状态。
路径：按用户明确要求直接构建基础 GUI，沿用平台组件体系。

Refero styles 对三个方向（中性精确排版、邮件效率、Linear 浅色界面）的查询均返回
NO_SUBSCRIPTION，未获取在线风格、屏幕或流程，不将其当作已研究的产品证据。
采用 Refero 技能随附 `typography.md`、`color.md`、`craft-details.md` 作为可用参考。

## 参考锁定

主方向：原生 macOS/Qt 控件与系统调色板。保留单字体、中性底色、紧凑导航、清晰标题与系统焦点。
次要参考：内置 typography 的工作工具中性排版与有限字号；craft-details 的明确标签和异步反馈。
颜色角色：系统强调色只用于选中项、焦点和交互；不覆盖系统深色模式，不添加装饰渐变或图片。
媒体策略：此阶段无需位图资产。主要布局由原生控件直接表达。

| 决策 | 来源与角色 | 实现 |
| --- | --- | --- |
| 六项侧栏导航 | 用户需求，固定主导航 | QListWidget + QStackedWidget |
| 正文 13pt，章节 17/19pt，页标题 26pt | typography：单字体、有限层级 | 系统字体，不引入远程字体 |
| 中性背景、系统强调色 | color：中性占主导，强调色只表达状态 | 默认 QPalette，不硬编码浅色 |
| 长内容可滚动，最小窗口 820×600 | craft-details：溢出与可访问性 | QScrollArea、可换行标签 |
| 三步引导、可取消并再次进入 | 用户首次启动向导要求 | 介绍 → 隐私 → 阶段说明，仅保存本地标记 |
| 无假数据，空状态标明里程碑 | 用户分阶段要求 | 明确 M1/M2/M3 功能进度 |
| 可见数据状态与备份结果 | 用户可恢复性优先级 | 设置页显示迁移/WAL、异步备份及位置 |

验证方法：真实 Qt 渲染后检查今日、首次引导与设置截图；测试导航、引导完成/取消、后台操作与错误反馈。
系统深色模式由原生样式跟随；未改变用户的系统外观。

实机检查发现 QWizard 默认背景加载 KeyboardSetupAssistant 资源时触发 NSBundle 空 URL
异常；最小复现确认显式非空透明背景可避免默认资源回退。引导使用 ModernStyle 并显式显示
取消按钮；这不影响其他控件的系统外观。
来源：[Qt QWizard 源码](https://github.com/qt/qtbase/blob/dev/src/widgets/dialogs/qwizard.cpp)。

最终已实际检查浅色和应用内深色 Cocoa 截图，两种外观均成功。引导“稍后设置”按钮可见，
今日与设置内容无截断；设置数据路径为临时测试目录。截图仅保存在忽略的 artifacts 目录。
